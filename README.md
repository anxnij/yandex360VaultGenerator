# YandexSvodApp

Приложение на Python для обновления файла `свод.xlsx` из публичной папки Яндекс.Диска 360.

## Для чего нужен проект

Программа ищет в указанной публичной папке Яндекс.Диска самый свежий `.xlsx`-файл, скачивает его и добавляет в локальный `свод.xlsx` только новые строки.  
При этом:

- используется только **первый лист** книги;
- лишние листы удаляются;
- форматирование уже существующего свода сохраняется;
- дубли не добавляются;
- фильтрация применяется только к строкам из свежего файла.

## Что делает программа

### Основной сценарий
1. Получает список файлов в публичной папке Яндекс.Диска через API.
2. Находит самый свежий `.xlsx`.
3. Скачивает этот файл во временную папку.
4. Если `свод.xlsx` ещё не существует — создаёт его на основе свежего файла.
5. Загружает первый лист `свод.xlsx`.
6. Читает первый лист свежего файла в `pandas.DataFrame`.
7. Применяет фильтры к добавляемым строкам:
   - удаляет полностью пустые строки;
   - удаляет строки, где поле **`Грузим?`** содержит одно из стоп-значений;
   - удаляет строки, где поле **`Разница за штуку`** попадает в диапазон от `-0.2` до `0.2` включительно.
8. Удаляет дубли внутри свежего файла.
9. Сравнивает строки со сводом по SHA1-ключам.
10. Добавляет только новые строки в конец `свод.xlsx`.
11. Копирует форматирование из шаблонной строки.
12. Сохраняет обновлённый файл и логирует результат.

## Структура данных и файлов

### Файлы приложения
Рабочая директория создаётся в:

`%APPDATA%\YandexSvodApp`

В ней лежат:

- `settings.json` — настройки приложения;
- `token.dpapi` — зашифрованный OAuth-токен;
- `last_run.log` — лог последнего CLI-запуска;
- `keys_<hash>.txt` — SHA1-ключи строк для конкретного файла свода.

### Итоговый файл
- `свод.xlsx` — локальный файл, который обновляется программой.

## Требования

### Python
Рекомендуемая версия:
- Python 3.11+  
  (минимум нужен Python 3.10+, так как в коде используются объединения типов вида `Decimal | None`)

### Зависимости
Установить:

```bash
pip install requests pandas openpyxl truststore pywin32
```

## Как запустить

### Вариант 1. Через интерфейс
```bash
python app.py
```

Дальше:
1. Указать ссылку на публичную папку Яндекс.Диска.
2. Выбрать папку, где лежит или будет лежать `свод.xlsx`.
3. Нажать **«Введите или обновите токен»**.
4. Вставить OAuth-токен Яндекса.
5. Нажать **«Обновить свод»**.

### Вариант 2. Через командную строку
```bash
python app.py --run-once --link="ССЫЛКА_НА_ПАПКУ" --outdir="ПУТЬ_К_ПАПКЕ"
```

Важно: токен должен быть заранее сохранён через интерфейс.

## Как работает защита от дублей

Каждая строка нормализуется:
- даты приводятся к единому виду;
- числа нормализуются;
- пустые значения приводятся к пустой строке.

После этого строится SHA1-ключ строки.  
Если такой ключ уже был сохранён в `keys_<hash>.txt`, строка считается дублем и не добавляется.

## Автозапуск

Программа умеет создавать ежедневную задачу через Windows Task Scheduler (`schtasks`).

Что делает автозапуск:
- запускает тот же исполняемый файл;
- передаёт режим `--run-once`;
- использует сохранённые ссылку и папку выгрузки;
- обновляет свод по расписанию.

## Типовые проблемы

### 1. Нет токена
Если токен не сохранён, ручной запуск и автозапуск не смогут скачать файл.

### 2. Ошибка доступа 401/403
Обычно это означает:
- токен истёк;
- токен не подходит;
- нет прав к ресурсу.

### 3. В публичной папке нет `.xlsx`
Функция `pick_latest_xlsx_item` выбросит ошибку, если подходящих файлов нет.

### 4. Повреждён `settings.json`
Программа просто вернётся к настройкам по умолчанию.

### 5. Потерян файл `keys_<hash>.txt`
Он будет автоматически пересобран на основе уже существующих строк `свод.xlsx`.



## Примечание
### 1. Фильтры применяются только к добавляемым строкам
Существующий `свод.xlsx` не очищается задним числом.

### 2. Форматирование копируется из шаблонной строки
Новые строки наследуют:
- шрифт;
- заливку;
- границы;
- выравнивание;
- формат числа;
- защиту;
- высоту строки.

### 3. Источник истины для структуры колонок — текущий `свод.xlsx`
Свежий файл подгоняется под заголовки уже существующего свода.

### 4. Сравнение строк идёт не по одной колонке, а по всей строке
Это важно, если в будущем появится задача делать дедупликацию по бизнес-ключу.

## Быстрый чек-лист перед изменениями

- проверить, не ломается ли форматирование новых строк;
- проверить сценарий первого запуска, когда `свод.xlsx` ещё не существует;
- проверить сценарий пересборки `keys_<hash>.txt`;
- проверить ручной запуск и `--run-once`;
- проверить автозапуск через `schtasks`;
- проверить работу фильтров на тестовом файле.
