Desktop-приложение на Python для автоматического обновления Excel-свода из самой свежей выгрузки в публичной папке Яндекс.Диска 360. Реализована интеграцию с API Яндекс.Диска, безопасное хранение OAuth-токена через Windows DPAPI, загрузка пользовательских настроек из AppData, поиск и скачивание актуального .xlsx-файла, фильтрация данных через pandas, удаление дублей с помощью SHA1-ключей и добавление только новых строк в итоговый Excel-файл с сохранением форматирования через openpyxl. Также добавлен графический интерфейс на Tkinter, пошаговый лог процесса и ежедневный автозапуск через Windows Task Scheduler.
В работе выполнено:
Интеграция с API Яндекс.Диска 360 через HTTP-запросы и библиотеку requests.
Работа с OAuth-токенами и безопасное хранение токена через Windows DPAPI.
Вынесение конфиденциальных параметров в отдельный config.json.
Загрузка настроек пользователя из AppData и сохранение состояния программы между запусками.
Автоматический поиск самого свежего Excel-файла в публичной папке Яндекс.Диска.
Постраничная загрузка данных из API и обработка JSON-ответов.
Скачивание файлов потоковым способом без полной загрузки в память.
Обработка Excel-файлов через pandas и openpyxl.
Формирование итогового файла свода с сохранением форматирования строк.
Удаление лишних листов и работа со структурой Excel-книги.
Нормализация данных: обработка заголовков, дат, денежных значений, пустых строк и текстовых статусов.
Поиск и исключение дублей через SHA1-хеширование строк.
Хранение ключей уже добавленных строк для инкрементального обновления свода.
Реализация фонового выполнения через отдельный поток, чтобы интерфейс не зависал.
Создание ежедневного автозапуска через Windows Task Scheduler.
Обработка ошибок доступа, отсутствия файлов, проблем с токеном и некорректных данных.
